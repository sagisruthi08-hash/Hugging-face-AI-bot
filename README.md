# 🤖 Mentora AI

### Your Intelligent Student Mentor

**Mentora AI** is an AI-powered student assistant designed to help college students with **learning, programming, Artificial Intelligence, Machine Learning, DBMS, Data Science, project guidance, and interview preparation**.

The application provides an interactive chatbot interface where students can ask questions and receive AI-generated responses using a pretrained Hugging Face language model.

---

# 📌 Project Overview

Students often need quick explanations, programming guidance, project ideas, and learning support while studying.

**Mentora AI** provides a simple and interactive platform where students can communicate with an AI assistant through a conversational interface.

The application is built using **Python, Streamlit, Hugging Face Transformers, and PyTorch**, with the **SmolLM2-360M-Instruct** model used for generating responses.

### 🎯 Main Objective

The main objective of Mentora AI is to create an accessible AI-powered learning assistant that can:

* Answer student questions
* Explain technical concepts
* Provide programming guidance
* Assist with academic subjects
* Support project development
* Help with interview preparation
* Maintain conversational chat history

# ✨ Features

## 🤖 AI-Powered Chatbot

Students can interact with **Mentora AI** using natural language and receive AI-generated responses to their questions.

## 📚 Learning Assistance

The chatbot helps students understand academic and technical concepts using simple and easy-to-understand explanations.

## 💻 Programming Support

Students can ask questions related to programming languages and concepts such as:

* Python
* Java
* Programming Fundamentals
* Object-Oriented Programming
* Algorithms

## 🧠 AI & Machine Learning

Mentora AI provides explanations and learning support related to:

* Artificial Intelligence
* Machine Learning
* Neural Networks
* Natural Language Processing
* AI Models

## 🗄️ DBMS Assistance

Students can ask questions about:

* Database Management Systems
* SQL
* Normalization
* Keys
* Tables
* Database Concepts

## 📊 Data Science Support

The chatbot can provide guidance related to:

* Data Analysis
* Data Visualization
* Machine Learning Concepts
* Data Science Fundamentals

## 💡 Project Guidance

Mentora AI can help students understand project concepts, generate project ideas, and provide guidance during project development.

## 🎯 Interview Preparation

Students can use the assistant to revise technical concepts, practice questions, and prepare for technical interviews and placements.

## 💬 Chat History

Conversation messages are maintained during the current session, allowing students to continue their discussions naturally.

## 🗑️ Clear Chat

Users can clear the current conversation using the **Clear Chat** button.

## 🎨 Interactive User Interface

The application provides a clean, simple, and student-friendly interface using **Streamlit**.

# 🤗 AI Model

Mentora AI uses the following pretrained Hugging Face model:

### **SmolLM2-360M-Instruct**

**Model:**

```text
HuggingFaceTB/SmolLM2-360M-Instruct
```

The model is responsible for generating responses to student questions and providing conversational AI assistance.
